# LRCファイルジェネレーター

MP3ファイルを再生しながら、歌詞にタイムスタンプを付けて正確なLRCファイルを作成するPythonアプリケーションです。

## 機能

- **MP3ファイルの再生**: MP3ファイルを選択して再生、一時停止、停止が可能
- **リアルタイムタイムスタンプ記録**: 再生中に歌詞を入力し、現在の再生位置でタイムスタンプを記録
- **歌詞管理**: 記録した歌詞の表示、最後の行の削除、すべてクリアが可能
- **LRCファイル出力**: 標準的なLRC形式でファイルを保存

## スクリーンショット

アプリケーションのメイン画面：
- MP3ファイル選択エリア
- プレーヤーコントロール（再生/一時停止/停止）
- 現在時間と総再生時間の表示
- 歌詞入力フィールド
- タイムスタンプ付き歌詞リスト
- 保存ボタン

## インストール

### 必要な要件

- Python 3.7 以上
- pip

### セットアップ

1. リポジトリをクローン:
```bash
git clone <repository-url>
cd python_practice
```

2. 必要なパッケージをインストール:
```bash
pip install -r requirements.txt
```

## 使い方

1. アプリケーションを起動:
```bash
python lrc_generator.py
```

2. MP3ファイルを選択:
   - 「MP3を選択」ボタンをクリック
   - MP3ファイルを選択

3. 歌詞の入力とタイムスタンプの記録:
   - 「▶ 再生」ボタンで再生開始
   - 歌詞の各行を「現在の行」フィールドに入力
   - その行が歌われるタイミングで「タイムスタンプを記録」ボタンをクリック（またはEnterキーを押す）
   - 自動的にタイムスタンプが記録され、次の行の入力が可能に

4. 編集:
   - 「最後の行を削除」: 最後に追加した歌詞行を削除
   - 「すべてクリア」: すべての歌詞データを削除

5. 保存:
   - 「LRCファイルとして保存」ボタンをクリック
   - 保存先とファイル名を指定

## LRCファイル形式

生成されるLRCファイルは以下の形式です：

```
[ti:曲名]
[ar:]
[al:]
[by:LRC Generator]

[00:12.34]最初の歌詞行
[00:18.56]二番目の歌詞行
[00:24.78]三番目の歌詞行
```

- `[mm:ss.xx]`: タイムスタンプ（分:秒.センチ秒）
- タイムスタンプの後に歌詞が続きます

## 使用技術

- **tkinter**: GUI フレームワーク（Python標準ライブラリ）
- **pygame**: MP3ファイルの再生
- **mutagen**: MP3ファイルのメタデータ読み取り

## トラブルシューティング

### MP3ファイルが再生できない

- MP3ファイルが破損していないか確認してください
- ファイル形式が正しいMP3であることを確認してください

### タイムスタンプがずれる

- pygameの再生位置取得には若干の誤差がある場合があります
- より正確なタイムスタンプが必要な場合は、再生を一時停止してから記録してください
